Frequently Asked Questions — Access Control

Technical FAQ for modern infrastructure security.

Which badge technology should we choose?
For new rollouts, the mandatory gold standard is Mifare DESFire EV2 or EV3 — leveraging advanced AES encryption, structural anti-cloning defenses, and a 10-year lifespan. Avoid outdated legacy legacy technology such as HID Prox 125 kHz or Mifare Classic arrays, which are vulnerable to simple smartphone cloning apps.
Are biometrics compliant with GDPR regulations?
Yes, subject to definitive parameters. Regulatory standards like the CNIL model require: biometric template data must be stored locally on the user's personal smartcard token (never in a centralized database architecture), an explicitly clear scope statement, a prior Data Protection Impact Assessment (DPIA), and transparent employee information campaigns. We handle this integration entirely.
Can access control be integrated with Active Directory?
Yes. User permissions are automatically provisioned directly via your Active Directory or enterprise HRIS directories (SAP, Workday, Oracle), and instantly revoked whenever an individual offboards. This eliminates lingering unrevoked "ghost tokens" — the leading vulnerability in physical corporate security breaches.
What is anti-pass-back?
Anti-pass-back rules dictate that a single card cannot log a second entry entry sequence without an intervening recorded exit scan. This effectively counters tailgating breaches where multiple entries attempt to use a single card. It is a critical requirement across highly secure operating perimeters like server infrastructure rooms or high-risk industrial facilities.
Does the entire building need to be rewired?
Not necessarily. Modern IP-PoE card readers deploy over standard RJ45 networking links, moving data throughput and power lines down one line. For system retrofits, wireless infrastructure alternatives (Wi-Fi, BLE, or long-range RFID) prevent structural wall work and reduce site downtime. Our assessment specifies the exact structural architecture needed.
How much does an access control system setup cost?
Pricing depends completely on system scope. As a general guide: estimate between €800 and €2,500 excl. tax per door for a standard IP-PoE Mifare DESFire deployment, excluding primary structural cabling runs. Real-world savings come from avoiding lock barrel updates from lost physical key sets (~€150 per replacement barrel) and mitigating ghost credential exposures.
